```
Madhav Krishna  //  Yung.Krshn
Head of Media & Frontend Dev @ Deffenso Hackers Academy
Founder & Creative Director @ FrameVerse
Founder @ SouthernSide — AI Education & GovTech
```

I build end-to-end AI-native products, civic technology systems, and developer tooling at the intersection of engineering and design. My work spans from panchayat-scale complaint infrastructure and ethical hacking education platforms to real-time computer vision experiments and production SaaS products — all designed to be deployable, monetizable, and maintainable from day one.

I approach every system with an interface mindset: architecture that thinks about the user, infrastructure that thinks about the developer, and product logic that thinks about scale. Prompt engineering is architecture. Design is structure. Both should survive production.

My technical foundation spans React, Next.js, Supabase, Firebase, Python, React Native, and the Anthropic API — unified by a consistent philosophy: **make AI usable, not just accessible.**

On the creative side, I document Kerala's living cultural traditions — Theyyam, Kathakali, Aranmula Vallamkali — through cinematic documentary photography under the FrameVerse brand.

## ⬡ Featured Projects

<details>
<summary><strong>SAHAYI — Kerala Panchayat Complaint Management System</strong></summary>

<br/>

A civic infrastructure platform designed to digitize and streamline citizen grievance routing across Kerala's panchayat system. SAHAYI handles district-based complaint routing, real-time FCM push notifications, role-based admin workflows, and multilingual support — built for production deployment at the local government level.

| Attribute | Details |
|-----------|---------|
| **Stack** | React Native · Supabase · React · PostgreSQL · Firebase Cloud Messaging |
| **Scale** | Multi-district panchayat network · Role-based access for citizens, officers, admins |
| **Performance** | Real-time status updates via Supabase Realtime · Sub-500ms notification delivery |
| **Security** | Row-level security policies · JWT auth · Role-scoped data access |
| **Impact** | End-to-end GovTech digitization · Complaint lifecycle from submission to resolution |
| **Repository** | [![GitHub](https://img.shields.io/badge/View%20Repo-1e1b4b?style=flat-square&logo=github&logoColor=white)](https://github.com/madhavkrishna/sahayi) |

SAHAYI was architected as a full technical PRD suite — citizen interface, admin dashboard, and tech stack spec — with production-grade database schema, FCM integration, and a React admin panel for tracking complaint status across jurisdictions. The system demonstrates that civic technology can be built with the same engineering discipline as enterprise SaaS.

<br/>
</details>

| **Impact** | Production LMS deployed at deffenso.in + lms.deffenso.in via GoDaddy DNS |
| **Repository** | [![GitHub](https://img.shields.io/badge/View%20Repo-1e1b4b?style=flat-square&logo=github&logoColor=white)](https://github.com/madhavkrishna/dflms) |
